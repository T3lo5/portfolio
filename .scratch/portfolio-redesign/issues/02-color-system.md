# 02: Sistema de cores próprio e remoção de gradientes decorativos

**What to build:** Uma paleta de cores própria (não o slate padrão do Tailwind), sem gradientes decorativos, com dark mode de identidade própria. O site deixa de parecer um shadcn starter.

**Blocked by:** None (can start immediately)

**Status:** done (Sprint 1 — Foundation)

- [x] Paleta definida por tokens CSS: fundo claro (off-white quente), foreground (preto/near-black), superfície (tom derivado), 1 cor de destaque.
- [x] Nenhum gradiente usado como decoração permanece no código.
- [x] Dark mode usa tokens distintos, não é inversão do light mode.
- [x] Cor de destaque aparece apenas em: links principais, estado ativo de navegação, botão primário (e assinatura .sig).
- [x] Nenhuma cor roxa/azul padrão como cor de destaque (accent verde #15803d).
